# ระบบแจ้งซ่อมบำรุงและติดตามสถานะ (SmartFix Pro)

เว็บแอปพลิเคชันระบบบริหารจัดการงานแจ้งซ่อมบำรุงและติดตามสถานะงานซ่อมแบบเรียลไทม์ พร้อมบันทึกประวัติการซ่อมบำรุง เชื่อมต่อฐานข้อมูล **MySQL** โดยมีระบบ Fallback ในตัวที่ทำให้เปิดใช้งานได้ทันที 100%

---

## 🌟 ฟังก์ชันหลักและหน้าจอทั้ง 4 หน้า (ตามความต้องการ)

1. **หน้าหลัก (Home / Dashboard)**
   - แสดงภาพรวมระบบด้วยภาพประกอบ 3D Hero Banner สุดทันสมัย
   - ช่องค้นหาด่วน (Quick Search) เพื่อตรวจสอบสถานะงานซ่อมได้จากหน้าแรกทันที
   - การ์ดสถิติ KPI 4 หมวดหมู่ (งานทั้งหมด, รอดำเนินการ, กำลังซ่อมบำรุง, ซ่อมเสร็จสิ้น)
   - รายการแจ้งซ่อมล่าสุด (Recent Requests Feed) อัปเดตแบบเรียลไทม์
   - แผนภาพขั้นตอนการดำเนินงานซ่อมบำรุง 4 ขั้นตอน (Workflow Guide)

2. **หน้าแจ้งปัญหา (Report Issue Form)**
   - ข้อมูลที่ต้องกรอกครบถ้วนตามที่ระบุ:
     - **ปัญหาที่เกิด** (พร้อมปุ่มเลือกตัวอย่างอาการเสียเพื่อความรวดเร็ว)
     - **ชื่ออุปกรณ์** (มี Dropdown รายการอุปกรณ์มาตรฐานให้เลือก เช่น PC, โน้ตบุ๊ก, ปริ้นเตอร์, แอร์, โปรเจกเตอร์, โทรศัพท์, อุปกรณ์เน็ตเวิร์ก หรือเลือก "อื่นๆ" เพื่อพิมพ์ระบุเองได้)
     - **ชื่อรุ่น / ยี่ห้อ / รหัสครุภัณฑ์**
     - **ชื่อผู้แจ้งปัญหา**
     - ข้อมูลเสริม: แผนก, สถานที่ตั้งอุปกรณ์, เบอร์โทรติดต่อ, ระดับความเร่งด่วน (ปกติ, เร่งด่วน, ด่วนที่สุด)
     - ระบบแนบรูปภาพปัญหาชำรุด (Drag & Drop หรือคลิกเลือกรูป)
   - เมื่อส่งข้อมูล: แสดง Modal ใบรับแจ้งซ่อม พร้อมรหัสติดตาม (เช่น `REQ-2026-0001`), ปุ่มคัดลอกรหัส, ปุ่มพิมพ์ใบแจ้งซ่อม (Print Slip) และปุ่มไปยังหน้าติดตามสถานะทันที

3. **หน้าติดตามสถานะ (Track Status)**
   - ค้นหาด้วย **รหัสติดตามงานซ่อม (Tracking Code)** หรือ **เบอร์โทรศัพท์**
   - มีปุ่มทางลัดรหัสตัวอย่างสำหรับการทดสอบทันที
   - **เส้นทางความคืบหน้างวดงานแบบ 4 ขั้นตอน (Interactive Visual Timeline Stepper)**:
     1. ได้รับแจ้งซ่อม (Request Received)
     2. มอบหมายช่าง (Assigned)
     3. กำลังซ่อมบำรุง (In Progress)
     4. ซ่อมเสร็จสิ้น / พร้อมส่งมอบ (Completed)
   - แสดงรายละเอียดอุปกรณ์ อาการเสีย ผู้แจ้ง วันที่แจ้ง รูปภาพปัญหา
   - แสดงข้อมูลฝ่ายช่าง: ช่างผู้รับผิดชอบ, บันทึกการดำเนินงาน, วันที่คาดว่าจะเสร็จ, ค่าใช้จ่าย
   - **แผงควบคุมฝ่ายช่าง / ผู้ดูแล (Admin/Technician Drawer)** สามารถเปลี่ยนสถานะ บันทึกช่าง และอัปเดตความคืบหน้าลงฐานข้อมูล MySQL ได้โดยตรงแบบ Real-time
   - ปุ่มพิมพ์ใบแจ้งซ่อม (Print Slip)

4. **หน้าประวัติการแจ้งปัญหา (Maintenance History)**
   - ตารางรวบรวมประวัติการแจ้งซ่อมทั้งหมดอย่างเป็นระบบ
   - ตัวกรองขั้นสูง: ค้นหาคำสำคัญ, กรองตามสถานะงาน, กรองตามประเภทอุปกรณ์, กรองตามระดับความเร่งด่วน
   - ปุ่ม **ส่งออกข้อมูลเป็น Excel / CSV** (รองรับภาษาไทย UTF-8)
   - ปุ่ม **พิมพ์ตารางรายงาน (Print Table)**
   - หน้าต่างแสดงรายละเอียดเชิงลึก (Detail Modal) พร้อมประวัติการซ่อม
   - ปุ่มจัดการรายการ (ดูรายละเอียด, ติดตาม/อัปเดต, ลบรายการ)

5. **ระบบจัดการฐานข้อมูล MySQL**
   - มีปุ่มแสดงสถานะ Database ที่แถบเมนูด้านบน
   - หาก MySQL เชื่อมต่อได้ จะสร้าง Database `maintenance_db` และตารางต่างๆ ให้อัตโนมัติ
   - หากยังไม่ได้ตั้งรหัสผ่าน MySQL ระบบจะมี Local Storage สำรองเพื่อไม่ให้เว็บหยุดชะงัก พร้อมเปิด Modal ให้กรอกรหัสผ่าน MySQL เพื่อกดเชื่อมต่อได้ทันทีจากหน้าเว็บ!

## 🚀 วิธีการติดตั้งและเริ่มใช้งาน

### 1. เปิด Terminal / PowerShell
ไปที่โฟลเดอร์โปรเจกต์:
```powershell
cd "C:\Users\usaja\Desktop\Web Project\Maintenance Request"
```

### 2. ติดตั้ง Dependencies (ทำครั้งแรก)
```powershell
cmd.exe /c "npm install"
```

### 3. ตั้งค่าฐานข้อมูล MySQL (เลือกทำได้ 2 วิธี)

#### วิธีที่ ก: ผ่านไฟล์ `.env`
เปิดไฟล์ `.env` แล้วแก้ไขรหัสผ่าน MySQL ของคุณ:
```env
PORT=3000
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=รหัสผ่าน_mysql_ของคุณ
DB_NAME=maintenance_db
```
*(ระบบจะสร้างฐานข้อมูล `maintenance_db` และตารางทั้งหมดให้อัตโนมัติเมื่อเริ่ม Server)*

#### วิธีที่ ข: Import ไฟล์ `database.sql` ด้วยตัวเอง
นำไฟล์ `database.sql` ไป Execute หรือ Import ใน **phpMyAdmin** หรือ **MySQL Workbench** ได้ทันที

### 4. รันโปรแกรม
```powershell
node server.js
```

### 5. เข้าใช้งานผ่านเว็บเบราว์เซอร์
เปิดเบราว์เซอร์แล้วไปที่:
👉 **http://localhost:3000**
